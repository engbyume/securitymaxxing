# securitymaxxing

A first-pass application-security skill for software planning, building, changing, reviewing, testing, and release preparation.

## Use

Load SKILL.md before matching security specialists. Load designmaxxing in the same first pass when user-facing UI/UX is in scope. Follow the target-authorization rules in SKILL.md.

## Package

- SKILL.md contains the security workflow and specialist routing.
- references/application-security-checks.md contains the 70 core application-security checks.
- references/conditional-platform-security-checks.md contains 19 additional checks for matching platform and lifecycle risks.
- references/stack-preferences.md documents the preferred web stack and cloud provider selection rules.
